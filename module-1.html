CODE101 · Term 1, Year 1

Introduction to Programming

A first module on procedural and object-oriented programming, assessed through weekly labs, a paired coursework project, and a written exam.

Learning outcomes

as set by the module
  1. Design and implement simple programs using variables, control flow, and functions.
  2. Apply basic object-oriented principles to structure a small codebase.
  3. Test and debug code systematically, and explain design decisions to others.

Artefacts

what you produced, and the feedback it received

Library catalogue CLI

A command-line tool for adding, searching, and checking out books, built in pairs as the main coursework piece. View on GitHub

Feedback — Module tutor Clean separation between the data layer and the CLI, but error handling on bad input was inconsistent.

Weekly lab exercises

Ten short exercises covering loops, functions, and simple data structures, submitted individually each week.

Feedback — Lab demonstrator Solid grasp of control flow by week 4; encouraged to write more tests before checking answers against expected output.

Reflection

what did I actually learn, and how?

The biggest shift this module was learning to break a problem down before writing any code — the first two lab exercises I attempted directly in the editor took far longer than the ones I sketched out on paper first. Pairing on the coursework also showed me how differently two people can structure the same problem, which was uncomfortable at first but pushed me to justify decisions I'd normally make on autopilot.

The tutor's feedback on error handling was the most useful correction I received: I'd been coding for the "happy path" and not thinking about what a user could do wrong. Going into the next module, I want to write at least one deliberately-broken test case before I consider a function finished.
